# AI 桌宠

基于 **Tauri 2 + React + TypeScript + Rust** 的 Windows 桌面助手，包含透明置顶桌宠、文字对话、屏幕观察、游戏场景建议，以及可选的 GPT-SoVITS 语音播报和语音输入。

仓库只提供源码和界面资源，不包含 API Key、个人设置、聊天记录、录音、语音模型、历史备份或即用发布包。模型服务与语音服务需要自行配置。

## 1. 准备环境

- Windows 10/11（当前实现包含 Windows 专用能力）。
- Node.js 20+ 与 npm。
- Rust stable，使用 MSVC 工具链。
- Visual Studio Build Tools，安装“使用 C++ 的桌面开发”与 Windows SDK。
- Microsoft Edge WebView2 Runtime。
- 可选：Tesseract OCR，加入 PATH，并安装中文 `chi_sim` 与英文语言数据。未安装时 OCR 可能为空。

在 PowerShell 中确认 `node --version`、`npm --version` 和 `cargo --version` 能正常执行。

## 2. 安装与启动

下载或克隆本仓库，进入项目根目录（含 `package.json` 的目录）：

```powershell
npm ci
npm run tauri dev
```

也可以在安装好环境后运行根目录的 `run-desktop-pet.cmd`。

首次启动默认待机，不会自动开始周期性看屏。打开设置中心，完成模型配置后再启用观察。

`npm run dev` 仅启动前端预览；桌面截图、凭据保存和本地语音等功能需要通过 `npm run tauri dev` 运行。

## 3. 配置对话与看屏

1. 打开设置中心的模型配置，选择服务商预设或自定义兼容接口。
2. 填写 Base URL（通常以 `/v1` 结尾）、聊天模型与视觉模型名称。程序会在 Base URL 后追加 `/chat/completions`，不要重复填写完整接口路径。
3. 在应用界面输入自己的 API Key。不要把密钥写入源码、README 或提交到 Git。
4. 先发送一条文字消息，确认连接正常，再开启屏幕观察。
5. 看屏需要服务商支持图片输入，并填写可用视觉模型。当前代码对 DeepSeek 配置使用窗口信息与 OCR 文本，不发送图片；模型是否可用以自己的服务商账号为准。

可切换办公、互动、游戏模式，调整回复间隔与智能观察选项。低配设备可以启用低配模式、延长观察间隔。模型 API 调用可能产生服务商费用。

## 4. 配置语音播报（可选）

不需要语音时，在设置中关闭播报，或把语音引擎设为 `none`，即可先使用文字功能。

需要播报时：

1. 自行安装 GPT-SoVITS，并准备有权使用的 GPT/SoVITS 权重与参考 WAV 音频。仓库不附带模型和录音。
2. 启动兼容 `api_v2.py` 的服务；默认地址为 `http://127.0.0.1:9880`。
3. 在设置中填写本机 GPT-SoVITS 根目录、GPT 权重路径、SoVITS 权重路径、参考音频绝对路径、参考音频对应文本与语言。
4. 可使用应用中的本地服务启动与权重加载功能，或连接已经启动的服务。确认服务可用后再测试播报。

这些路径默认为空，必须按自己的电脑填写。参考文本应与参考音频内容一致。语音服务位于其他机器时，文件路径必须能被该服务访问。

## 5. 配置语音输入（可选）

- 默认关闭，可选择按住说话或连续监听。
- 本地识别默认接口为 `http://127.0.0.1:8000/v1/audio/transcriptions`，需要自行部署兼容的转写服务；此仓库没有附带识别服务器。
- 使用云端识别时，填写转写接口、模型和单独的语音 API Key。
- 允许系统麦克风访问；可启用全局热键，默认键值对应 F8。
- 播报期间会暂缓监听，播报结束后的等待时间可以调整。

## 6. 隐私与数据

- 对话和语音识别 API Key 使用 Windows Credential Manager 保存；普通设置保存及预设导出会移除这两个密钥字段。
- 看屏时，窗口标题、进程信息、OCR 文本以及支持视觉输入时的截图，会发送到配置的模型服务。文字聊天会发送当前对话上下文；启用记忆时也可能包含保存的偏好。
- 截图处理使用内存；语音输入会创建临时录音文件，正常流程结束时尝试清理。云端转写会将录音发送到配置的识别服务。
- 可暂停观察、进入勿扰，或在黑名单中加入窗口标题/进程关键词，减少敏感窗口被观察的机会。
- 记忆默认关闭，启用后在本地保存显式偏好摘要。普通设置、角色预设、参考音频路径和导出 JSON 仍可能包含私人信息；不要直接上传个人导出文件。
- `.gitignore` 排除本地备份、发布包、缓存、环境文件、密钥文件、录音及模型等。不要使用 `git add -f` 强制添加这些内容。

## 7. 检查与打包

```powershell
# 运行现有单元测试
npm test

# TypeScript 检查与前端构建
npm run build

# 构建 Windows 安装程序（需要完整 Rust/C++ 环境）
npm run tauri build
```

默认 NSIS 安装包输出到 `src-tauri/target/release/bundle/nsis/`。`npm run build` 本身不会生成桌面安装包。

## 常见问题

| 问题 | 排查方式 |
| --- | --- |
| 找不到 cargo / 链接器报错 | 安装 Rust MSVC 工具链、C++ Build Tools 和 Windows SDK，然后重开终端。 |
| 窗口空白 | 检查 WebView2；开发时确认通过 Tauri 命令启动。 |
| 模型返回 401/403 | 检查 API Key、接口地址与账号权限。 |
| 模型返回 404 或不支持图片 | 检查模型名及视觉能力，确认 Base URL 未重复包含 `/chat/completions`。 |
| 没有 OCR 文本 | 检查 Tesseract 是否在 PATH，以及语言数据是否安装。 |
| 没声音 | 检查播报开关、系统音量、9880 服务、权重与参考音频/文本。 |
| 语音识别失败 | 检查麦克风权限、识别服务、接口地址和语音密钥。 |
| 下载依赖失败 | 检查网络和包源设置；本机 `.cargo` 镜像配置不随仓库分发。 |

## 目录

- `src/`：界面、桌宠、配置、屏幕分析、语音和单元测试。
- `src-tauri/src/`：Windows 截屏、凭据、本地服务与音频能力。
- `src-tauri/tauri.conf.json`：桌面窗口与安装包配置。
- `src/assets/`、`src-tauri/icons/`：界面图片与应用图标。

角色图片和相关素材不代表与任何原作或品牌存在官方关联。对外分发时需确认所用素材与第三方模型的授权。
